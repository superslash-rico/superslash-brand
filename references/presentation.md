# 演示与 16:9 PDF

## 画布与字体

默认 16:9，建议使用 1280×720 px 设计坐标（96 DPI）；PPTX 对应 12192000×6858000 EMU。既有模板或用户明确的比例优先，包括历史课件的 3:2。不要为了默认 16:9 破坏提供的课件模板。

字体 MiSans，文字、表格与图表各自设置字体。设计坐标的 `fontSize` 常是 px；32 pt 等于约 42.7 px。避免把 A4 的 11.5 pt 用作演示正文。正文建议 24–30 px，标题 44–52 px，封面 64–80 px；查看投屏距离与最终渲染再调整。

同时设置 Office 原生主题，避免客户新增文字、表格或图表又回到默认字体和颜色。`scripts/brand_ooxml_theme.py INPUT OUTPUT` 可为新 DOCX/PPTX 设置 MiSans 主题字体与品牌色，保持其他文件部件不变。输出采用新路径，并在最终验收前应用；既有客户模板是否替换主题由当前任务决定。

### 深色客户汇报

使用 `assets/templates/客户汇报-16比9-深色.pptx` 参考：深石墨底、白色主文字、灰白正文，重点信息用 `#E802F8`。封面呼应 A4 客户方案的玻璃螺旋主视觉，采用专门的横版构图与可编辑渐变遮罩，保留安静的文字区。正文将表现力集中到关键结论与信息关系，表格使用深底和充足对比，人物与尾页保持同一品牌。

使用 `brand_ooxml_theme.py INPUT OUTPUT --variant dark` 设置深色原生主题；这会同步主文稿、幻灯片母版与备注母版的字体和颜色，避免新增内容回到浅色默认。品牌色强调不能替代必要的标签、单位或证据。引用题图只在主题吻合时使用；其他客户场景应更换主题视觉。

## 组织内容

从观众问题与所需决策安排页序。通常包括封面、必要的结构或概览、重点内容、下一步；数量和详略由实际任务决定。

- 汇报：结论与变化、证据、原因、行动及待决策项。
- 方案：客户需求、范围与选择、路径、责任与验收、下一步。
- 课程：学习目标、场景、概念、操作、结果、练习；结合可用 `course-ppt-production` 技能维护教学节奏。

一页重点明确，详细论证可留备注或附录。文字、Logo 和表格保留原生对象；图解与数据图表按需求保留可编辑性。摄影或生成图作为视觉资产，不能生成整页带中文的图片来替代 PPT。

## 设计

新制 PPT 和 16:9 汇报 PDF 使用 [官网首页风格](homepage-style.md)。浅紫封面或章节页承载大标题和一个主场景；正文以近白和浅蓝为主，短标签分层，图表与表格保留可编辑对象。

封面可以简洁文字、行业实景、主题图或真实产品。正文使用平面的文字、图片、表格与图解组合；以对齐、比例与留白组织信息。稳定的页脚保留品牌、域名或页码，避免在每页塞入完整公司联系信息。

人物页用原照片或批准的抠图，履历贴近人物；不要让照片遮住需要阅读的文字。咨询尾页保持 QR 原图与空白边界。内部汇报尾页可展示行动或待决策事项。

## 实际制作

使用当前可用 Presentations 技能，读取其实现与最终验收指南。当前 Codex 运行时优先 Artifact Tool；使用 workspace dependency loader 返回的 Node、包路径、Python、渲染器。原生 API 应查当前文档，避免把此技能创建时的插件绝对路径写成依赖。

`assets/templates/汇报演示-16比9.pptx` 是已验证的六页版式参考：封面、论述、原生比较表、行动页、讲师与联系尾页。实际任务不受六页数量约束。模板可用导入工具编辑。新制对外演示从品牌配置取 v1.0 标志，替换旧模板中封面、页脚、尾页和母版的旧标。需要保留的原生对象应在导入或重建后对照检查。

在私有制作目录导出候选文件，声明真实字体、尺寸、页数与必要的原生对象要求，调用当前格式技能的 finalizer 验证。重新导入最终 PPTX 并渲染每页。核对表格记录、文字完整性、备注与字体；必要时在目标应用测试，区分结构可编辑和实际应用操作验收。

当前 finalizer 的子进程需要 loader 对应的 `RUNTIME_NODE` 与 `RUNTIME_NODE_MODULES`，即使制作脚本本身已通过 `node_modules` 链接导入成功也要设置。PPT 导出 PDF 时同样检查字体；如果导出器使用 Fontconfig，可按 A4 文档指南提供任务内 MiSans 配置。

PPT 导出 PDF 保持 16:9，重新检查字体与每页布局。PDF 用于稳定阅读，PPTX 用于继续编辑；生成成功或缩略图好看都不能代替全部页面的验收。
